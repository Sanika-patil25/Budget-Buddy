## 📌 About the Project

Managing personal finances becomes easier when income, expenses, budgets, and savings can be viewed in one place.

**Budget Buddy** brings these essential financial management features together in a single browser-based application. It provides a dashboard for understanding financial activity, tools for organizing expenses, savings goal tracking, interactive charts, and downloadable PDF reports.

This project demonstrates my practical learning in frontend development, JavaScript programming, browser-based data storage, and third-party library integration.

## ✨ Key Features

| Feature | Description |
|---|---|
| 📊 Financial Dashboard | View total income, expenses, balance, and budget summaries. |
| 💵 Income Tracking | Record and manage income entries. |
| 💳 Expense Management | Organize expenses by category. |
| 🎯 Budget Planning | Set category-wise budget limits and monitor usage. |
| 🏦 Savings Goals | Create financial goals and track progress. |
| 📋 Transaction History | Review transactions and filter records. |
| 📈 Interactive Charts | Visualize spending patterns and budget usage. |
| 📄 PDF Reports | Download financial reports. |
| 💾 Local Data Storage | Save supported application data in browser Local Storage. |
| 📱 Responsive Interface | Use the application across supported screen sizes. |

## 🛠️ Technologies Used

- **HTML5** — Structures the application.
- **CSS3** — Handles styling, layout, and responsive design.
- **JavaScript** — Implements application functionality and interactions.

## 🚀 Getting Started

You can run Budget Buddy locally on your computer.

### Prerequisites

- A modern web browser, such as Google Chrome, Firefox, or Microsoft Edge.
- An internet connection to load the external libraries used by the application.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Sanika-patil25/Budget-Buddy.git
```

**2. Navigate to the project folder**

```bash
cd Budget-Buddy
```

**3. Run the application**

Open `index.html` in your web browser.

No separate backend server is required for the current version.

## 🔐 Data Storage and Limitations

Budget Buddy uses browser Local Storage instead of a server-side database.

- Data is stored locally in the browser.
- Data is not automatically synchronized across devices.
- Clearing browser storage may remove saved application data.
- The login interface does not provide secure server-side authentication.

**Important:** This project is intended for educational and portfolio demonstration purposes. Avoid entering sensitive financial information.
